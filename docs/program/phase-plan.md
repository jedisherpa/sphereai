# Phase Plan by Wave

## Wave 0 — Program Setup and Charter
Outputs: charter artifacts, scope boundaries, risk register, definition-of-done, repository structure proposal.

## Wave 1 — Research and Option Analysis
Outputs: domain research docs, decision matrix, licensing audit, benchmark plan, recommended stack.

## Wave 2 — Verification Spikes and Architecture Lock
Outputs: runnable spikes for OCR/ASR/diarization/runtime/storage/connector; architecture docs and ADRs.

## Wave 3 — Core Implementation
Outputs: backend, queue, OCR/ASR pipelines, search/export, frontend flows, optional helper skeleton, CI draft.

## Wave 4 — Integration and Hardening
Outputs: reliability and performance tuning, restart resilience, failure/recovery docs, OS edge-case notes.

## Wave 5 — Quality, Cleanup, and Documentation
Outputs: test expansion, cleanup/refactors, security/privacy verification, maintainer-grade docs.

## Wave 6 — Packaging and Release
Outputs: installable artifacts/scripts, release notes, support matrix, known issues, rollback plan, final summaries.
