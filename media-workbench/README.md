# Local Media Workbench (Independent Project)

This directory contains a **standalone project** for the local-first media capture/OCR/transcription program.
It does **not** depend on the existing `sphere` CLI package in this repository.

## Purpose of current state
This commit advances **Wave 1 (Research and Option Analysis)** and includes a minimal standalone Python package scaffold to ensure the project can build/run independently.

## Quick check
```bash
cd media-workbench
python -m media_workbench.main
```
